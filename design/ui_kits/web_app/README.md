# Dictum Web App — UI Kit

The main legal-AI workspace. A warm, document-centric interface for lawyers and paralegals to ask legal questions, draft documents, and manage client matters.

## Screens
1. **Dashboard** — adaptive home; recent docs + frequent statutes + AI chat entry
2. **Chat** — conversational legal Q&A with inline citations
3. **Document Editor** — split view; AI review panel highlights typos / critical moments
4. **Clients** — saved client records auto-filled into drafts

## Components
- `Sidebar.jsx` — workspace + statutes nav
- `TopBar.jsx` — search, user, language toggle
- `Composer.jsx` — chat input with attach
- `ChatThread.jsx` — bubbles, citations, sources panel
- `DocumentCard.jsx` — file tile
- `Button.jsx`, `Badge.jsx`, `Alert.jsx`, `Input.jsx` — primitives
- `ClientRow.jsx`, `StatutePill.jsx`

Open `index.html` for the click-thru prototype.
